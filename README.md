# Engineering Feed Calculation System

React + Vite + Tailwind CSS engineering calculator for HotFace, ColdFace, Big Dia, Small Dia, X, and Y outputs.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run lint
npm run build
npm run preview
```

The production output is generated in `dist/`.

## Deployment

Use these settings on common static hosts:

- Build command: `npm run build`
- Publish/output directory: `dist`
- Node project type: Vite / static site

Netlify SPA fallback is provided by `public/_redirects`.
Vercel SPA fallback is provided by `vercel.json`.
